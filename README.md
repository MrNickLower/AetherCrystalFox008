# Aether Crystal Fox — Forge 1.18.2

**Project type:** Minecraft Forge mod source project  
**Minecraft:** 1.18.2 · **Forge:** 40.2.21 · **Java:** 17  
**Mod ID:** `aethercrystalfox`

## Included gameplay (English in-game text)
- A peaceful, tamable Aether Crystal Fox that can spawn in forest biomes.
- Killing it gives no drops.
- Tame it with sweet berries.
- Feed a tamed fox an **Aether Bloom** to charge its crystal. After the charge period, interact with it using an empty hand to collect an **Aether Shard**.
- Craft an **Aether Edge** sword from Aether Shards and a stick.
- Includes an original pixel texture and item textures.

## Important
This ZIP is the **complete source project**, not a precompiled `.jar`. It must be built with ForgeGradle and Java 17. This chat environment cannot verify a successful Forge build, and a phone alone generally cannot compile a Forge mod easily. The easiest route is to send this ZIP to a computer with Java 17 and Gradle/ForgeGradle access, then run `gradlew build` (or `gradle build` if Gradle is installed). The output JAR will be in `build/libs/`.

## Build
1. Install a Java 17 JDK.
2. Extract this ZIP.
3. In the project folder, run `gradle build` (or use a compatible Gradle wrapper if you add one).
4. Copy `build/libs/aethercrystalfox-1.0.0.jar` into the Minecraft instance's `mods` folder with Forge 1.18.2.

## Controls / recipe
- Tame: right-click the fox with Sweet Berries.
- Charge: right-click a tamed fox with Aether Bloom.
- Collect: after the charge finishes, right-click the tamed fox with an empty hand.
- Sword recipe: 2 Aether Shards vertically above 1 Stick.
